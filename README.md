# ShelfPilot
The scenario is a fictional retail SaaS company, ShelfPilot, and a fictional enterprise customer, Brightmart Retail. You play both sides: the customer's IT team running the identity provider (Keycloak), and the TAM building and debugging the connection.

# Keycloak Container image
Usage
run `docker compose up`
Access [keycloaks interface](http://localhost:8080/admin/master/console/)
For more information check out the [container guide](https://www.keycloak.org/server/containers) , and [other server guides](https://www.keycloak.org/guides#server).
